# Password Security Tool

A Python project that checks password strength and demonstrates secure
password storage using hashing and salting.

## Technologies Used
- Python
- bcrypt

## How to Run
1. Install bcrypt:
   pip install bcrypt
2. Run:
   python app.py

## What It Does
- Checks password strength
- Gives improvement suggestions
- Hashes passwords using bcrypt
- Verifies passwords safely

## What I Learned
- Why passwords should not be stored as plain text
- How hashing and salting protect passwords
- How to verify passwords securely
